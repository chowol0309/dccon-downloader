# 디시콘 다운로더

디시인사이드의 **디시콘 정보 창**에 `다운` 버튼을 추가합니다.
누르면 디시콘 한 세트를 `통합폴더/<디시콘 이름>/` 에 번호 순서대로 저장합니다.

```
디시콘/
├── [디시콘 이름 1]/
│   ├── 01.png
│   ├── 02.png
│   └── ...
└── [디시콘 이름 2]/
    └── ...
```

## 설치 (Tampermonkey 스크립트, 권장)

1. 브라우저에 [Tampermonkey](https://www.tampermonkey.net/)를 설치합니다.
   - 크롬/웨일: 확장 프로그램 관리 페이지에서 **개발자 모드**를 켜고, Tampermonkey 세부정보에서 **사용자 스크립트 허용**도 켜야 합니다.
2. 아래 링크를 열면 Tampermonkey 설치 화면이 뜹니다. **설치**를 누르세요.
   - https://raw.githubusercontent.com/chowol0309/dccon-downloader/main/dccon-downloader.user.js

## 사용법

1. 디시에서 디시콘을 클릭해 **디시콘 정보** 창을 엽니다.
2. 제목 옆 **다운** 버튼을 누릅니다.
3. 처음 한 번만 디시콘을 모아둘 **통합 폴더**를 고릅니다. (예: 다운로드 안에 `디시콘` 폴더를 만들어서 선택)
   - "파일 수정을 허용할까요?"라는 질문이 뜨면 허용해주세요.
4. 이후에는 누르기만 하면 바로 저장됩니다.

- 통합 폴더를 바꾸려면 다운 버튼을 **Shift+클릭**하세요.
- 브라우저 다운로드 기능을 쓰지 않고 폴더에 직접 저장하므로, "다운로드 전에 저장 위치 묻기" 설정이 켜져 있어도 파일마다 묻지 않습니다.
- 갤러리(`gall.dcinside.com`)와 디시콘샵(`dccon.dcinside.com`)은 브라우저가 다른 사이트로 취급해서, 각각 처음 한 번씩 폴더를 골라야 합니다.

## 확장 프로그램 버전

Tampermonkey 없이 쓰려면 이 저장소를 내려받아 확장 프로그램으로 불러올 수도 있습니다.

1. `chrome://extensions` (웨일: `whale://extensions`) → **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → 이 저장소 폴더 선택

확장 프로그램 버전은 브라우저 다운로드 기능으로 `다운로드/디시콘/<디시콘 이름>/` 에 저장합니다.
"다운로드 전에 저장 위치 묻기" 설정이 켜져 있으면 파일마다 저장 창이 뜨니, 이 경우엔 스크립트 버전을 쓰세요.

## 주의

- **개인 소장용입니다.** 받은 디시콘의 저작권은 각 제작자에게 있으며, 재배포나 상업적 이용을 금지합니다.
- 디시 사이트 구조가 바뀌면 동작하지 않을 수 있습니다.
